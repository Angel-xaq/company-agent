# IT 指南

## 账号与密码

公司账号用于登录邮箱、办公系统和会议室预约平台。密码需至少 8 位，并包含字母和数字。建议每 90 天更换一次密码。

忘记密码时，可通过 IT 服务台重置。重置后需在 24 小时内完成首次修改。禁止将账号借给他人使用。

## 网络与 VPN

办公区无线网络名称为 Company-Office，员工使用公司账号登录。外部办公时，请先连接公司 VPN，再访问内部系统。

VPN 客户端可在 IT 服务台下载。连接失败时，请检查账号状态和网络环境，必要时联系 IT 支持。

## 设备申领

新员工入职时由 IT 部门统一配发电脑和显示器。设备故障可通过服务台提交工单，紧急问题可拨打 IT 支持电话。

个人不得擅自拆装公司设备。设备遗失或损坏应及时上报，并按公司资产管理规定处理。

## 软件安装

办公软件由 IT 部门统一安装。需要额外软件时，请提交软件申请，说明用途和授权情况。未经批准不得安装来源不明的软件。

## 服务台

IT 服务台工作时间为工作日 09:30 至 18:30。非工作时间遇到影响业务的紧急故障，可通过值班电话联系。

提交工单时请提供问题描述、截图、设备编号和联系方式，以便快速定位问题。
